Feature 1: Christian Quotes Engine

Overview

Automated scraping pipeline that collects quotes from notable Christian authors, stores them in a dedicated database table, and makes them available for content generation. Built as a standalone system — no calendar or posting integration until manually approved.

Database

christian_quotes table:
  id              INTEGER PRIMARY KEY
  author          VARCHAR(200) NOT NULL
  quote_text      TEXT NOT NULL
  text_hash       VARCHAR(64) UNIQUE NOT NULL  -- SHA-256 for dedup
  source          VARCHAR(500)                 -- book, sermon, etc.
  tags            JSON DEFAULT '[]'            -- [faith, marriage, hardship, ...]
  scraped_from    VARCHAR(2000)                -- source URL
  scraped_at      DATETIME
  approved        BOOLEAN DEFAULT TRUE
  created_at      DATETIME DEFAULT NOW()

CLI Commands

  • manage.py scrape-quotes — run scraper manually
  • manage.py list-quotes [--author=lewis] — browse stored quotes
  • manage.py generate-quote-content — test content generation from a quote

Feature 2: Dynamic Caption Reels (Phrase Pop)

Overview

New reel rendering style where text appears phrase-by-phrase synced to TTS narration — the dominant format on Reels/TikTok for reach. Uses ElevenLabs word-level timestamps to drive FFmpeg text overlays.

Pipeline

  1. Text input (Bible verse or Christian quote)
  2. ElevenLabs TTS generates audio + word-level timestamps
  3. Group words into 3-5 word phrases based on natural breaks
  4. FFmpeg renders Ken Burns background + phrase overlays at exact timestamps
  5. Audio mix: narration + mood-matched music (same as existing)
  6. Output: 1080x1920 MP4 reel

Phrase Rendering

  • Large bold white text, centered on screen
  • Slight drop shadow for readability
  • Fade-in on phrase start, fade-out before next phrase
  • Font: same brand fonts (Georgia bold)
  • Background: Ken Burns zoompan on Unsplash image (same as existing)

ElevenLabs Timestamps

ElevenLabs with_timestamps=True returns character-level alignment data. We convert to word boundaries, then group into natural phrases using punctuation and word count rules.

CLI Commands

  • manage.py test-phrase-reel --content-id 63 — generate a phrase-pop reel from existing content
  • manage.py test-phrase-reel --text "The quote text" --voice 0 — generate from arbitrary text

Integration (Future — NOT part of this build)
