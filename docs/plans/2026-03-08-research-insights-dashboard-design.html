Research & Insights Dashboard — Design

Date: 2026-03-08 | Status: Approved

Overview

Add a unified "Insights" tab to the dashboard that combines competitor content analysis with own-performance data to generate actionable content recommendations. The goal: open the tab, immediately know what to change this week.

Design Decisions

  • Unified tab (not separate competitor + performance pages) — value comes from combining both data sources
  • Medium-depth competitor scraping — Instagram Graph API for recent posts (captions, media types, timestamps, hashtags). No Claude analysis yet (can add later as toggle).
  • Scrape frequency — Twice weekly (Monday 5:00 AM + Thursday 5:00 AM EST), last 10 posts per competitor, 5 competitors
  • Recommendations first — Actionable cards at top, data drill-down below
  • Performance by 3 dimensions — Content type, media format, posting time
  • No LLM calls — All analysis is pure Python rules engine against DB data

Dashboard Layout

Section 1: Recommendations (Top)

3-5 actionable cards. Each card:

  • Title: Short directive ("Double down on carousels", "Shift noon posts to 6:30 AM")
  • Why: One sentence with supporting data
  • Confidence: High/Medium/Low badge based on data volume
  • Source icon: Your data, competitor data, or both

Generated server-side by rules engine in core/analytics/performance_analyzer.py.

Rule examples:

  • Content type X has 2x+ engagement vs average → recommend more of it
  • Format Y has 2x+ reach vs other formats → recommend shifting to it
  • Morning posts outperform noon by 30%+ → recommend time shift
  • Competitor increased format Z by 50%+ → flag the trend
  • You don't post format Z but competitors do → flag the gap

Section 2: Your Performance Breakdown (Middle)

Three sub-panels side by side, shared time period selector (7/30/60/90 days):

  1. By Content Type — Horizontal bar chart. Each content type with avg engagement rate + avg reach. Sorted by engagement. Color-coded by existing content type colors.
  2. By Format — Horizontal bar chart. Reel / Carousel / Static Image. Avg reach, avg engagement rate, avg saves.
  3. By Posting Time — Morning (6:30 AM) vs Noon (12:00 PM). Avg reach, avg engagement rate per slot.

Section 3: Competitor Activity (Bottom)

Collapsible cards per competitor:

  • Summary row: Username, follower count, posts/week, dominant format
  • Format mix bar: Horizontal stacked bar (reel/carousel/image distribution)
  • Recent posts table: Timestamp, media type, caption preview (100 chars), hashtag count
  • Trend indicator: Format shift detection vs previous scrape

Backend Components

New Module: core/scraper/competitor_content.py

Scrapes competitor post data via Instagram Business Discovery API:

  • Endpoint: GET /{our-ig-user-id}?fields=business_discovery.fields(media{id,caption,media_type,timestamp,permalink}).username(competitor)
  • Requires: instagram_basic permission (already in our token scopes)
  • Falls back to public profile HTML scraping if business discovery unavailable
  • Stores results in competitor_posts table

New Module: core/analytics/performance_analyzer.py

Pure Python analysis engine:

  • get_content_type_performance(days) — Avg metrics grouped by content_type
  • get_format_performance(days) — Avg metrics grouped by media format
  • get_time_slot_performance(days) — Avg metrics grouped by scheduled hour
  • get_competitor_activity(days) — Competitor post summaries + format distributions
  • generate_recommendations(days) — Combines all analyses, applies rule engine, returns ranked 3-5 insights

Tech Stack

  • Frontend: React 18, Recharts (bar charts), Tailwind CSS, Lucide icons
  • Backend: FastAPI, SQLAlchemy, Alembic migration
  • Scraping: Instagram Business Discovery API via httpx
  • Analysis: Pure Python (no LLM calls)
  • Scheduling: Celery beat (Mon + Thu 5:00 AM EST)
