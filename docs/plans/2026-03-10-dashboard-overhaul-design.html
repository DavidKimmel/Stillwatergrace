StillWaterGrace Dashboard Overhaul Design

Date: 2026-03-10 | Status: Approved

Full rebuild of the dashboard into a professional social media management tool. Calendar-centric, reel-first, with creator sandbox, competitor insights, and drag-and-drop scheduling. Inspired by: Iconosquare, Brandwatch, Hootsuite/monday.com, Databox.

1. Architecture & Navigation

Single-page React app with 4 main views via a collapsible left sidebar:

ViewPurpose
Calendar (home)Week view with post previews, drag-and-drop, post selection
CreatorSandbox to create custom posts, browse image library
InsightsCompetitor top posts, scraper data, performance metrics
SettingsGeneration config, scraper schedule, posting times

Sidebar: Slim left rail with icons + labels, collapsible. SWG logo at top, active view highlighted in gold. Deep green (#2D4A3E) background.

Top bar: Current week with prev/next arrows, "Generate" button (dropdown: 1-7 days), quick stats (posts scheduled this week, pending approval count).

2. Calendar View (Home Page)

Layout

7-column grid (Mon-Sun). Each column shows that day's posts.

Day Column Structure

  • Day header (e.g., "Mon Mar 11") with post count badge
  • Morning slot (6:30 AM) and Noon slot (12:00 PM) visually separated
  • Each post is a compact card (~120px reel thumbnail, content type badge, hook text truncated to 2 lines, status dot, provider badge)

Post Selection (Multiple Posts Per Slot)

  • Cards stack vertically within a time slot
  • Radio button on each card -- selected card is the "active" post for that slot
  • Active card: gold left border, full opacity
  • Inactive cards: slightly dimmed
  • Unselected posts remain as alternatives until posting time

Drag-and-Drop

  • Drag any card to a different day (drops into that day's slot list)
  • Gold highlight on target day as drop indicator
  • Using dnd-kit library

Card Actions (Kebab Menu)

  • Post Now
  • Delete
  • Open in Creator (edit/remix)
  • Swap to AI Image / Swap Reel
  • View Full Details (expand modal with captions, hashtags, reel player)

Click on card: Expands inline detail panel below calendar with full content preview, captions, hashtags, and reel video player.

3. Creator Sandbox

Layout

Two-panel view. Left: editor. Right: live preview (phone-frame mockup).

Editor Panel

  • Content type dropdown (daily_verse, encouragement, marriage_monday, etc.)
  • Text input -- textarea for custom quote/verse, or "Generate with AI" button
  • Image source toggle:
    • Library -- browse themed folders, search/filter, thumbnails
    • AI Generate -- text prompt, fal.ai generation, auto-saves to catalog
    • Unsplash -- search Unsplash directly
  • Narration toggle (on/off), picks voice from rotation
  • Reel style dropdown (classic, quick, cinematic)
  • "Create Reel" button

After Creation

  • Preview plays in right panel
  • "Post Now" -- posts immediately
  • "Add to Schedule" -- mini-calendar picker to drop into a day/slot

Image Library Browser

  • Grid of thumbnails organized by theme tabs (nature, people, faith, dramatic, interactive, botanical)
  • Shows usage count per image
  • "Unused" filter to surface fresh images
  • New AI images auto-file into correct theme folder via catalog

4. Insights View

Section A: Competitor Top Posts (top of page)

  • Cards showing top-performing competitor posts from latest scrape
  • Each card: thumbnail, handle, engagement metrics, caption preview, media type badge
  • "Inspire" button -- copies concept to Creator (content type + theme, not text)
  • Filter by: competitor account, media type, date range
  • Scraper runs every other day (Mon/Wed/Fri via Celery beat)

Section B: Performance Dashboard

  • KPI row: reach, engagement rate, likes, saves, shares (delta vs last week)
  • Chart: post performance over time (line chart, filterable by content type)
  • Best performing posts table with "Remix" button to create variation in Creator

Section C: Recommendations

  • AI-generated insights from performance analyzer
  • Trend alerts from competitor data

5. Generation Pipeline Changes

CurrentNew
Generate full 7-day week on SundayGenerate 1-7 days on demand via UI dropdown
3 static images + 1 reel per postReel only (drop feed_4x5, 1x1, story_9x16)
Carousel generates but often failsCarousel 2x/week (Wed + Sat), design TBD later
Unsplash + optional AI afterUnsplash first always, AI Image button for alternative
Scraper Mon/ThuScraper every other day (Mon/Wed/Fri)
generate-week CLI onlyAPI endpoint + UI button with day count param

Generation Flow

  1. User clicks "Generate" dropdown, picks 1-7 days
  2. API creates content slots for next N days based on calendar schedule
  3. For each slot: Claude generates text, Unsplash provides background, reel renders
  4. Carousel slots (Wed/Sat) get placeholder status -- design TBD
  5. All new content lands as pending in calendar (yellow dots)
  6. User reviews, approves, selects active post per slot

Post Selection Logic

  • Each time slot can have multiple posts (original + regenerated + creator posts)
  • Only the selected post gets picked up by Celery posting task
  • If nothing selected at posting time, slot is skipped (no auto-posting unreviewed content)

Image Catalog Integration

  • Every Unsplash download auto-registers in catalog.json under content type's theme
  • Every AI generation auto-registers under matching theme
  • Creator's library browser reads from catalog

UI Details

  • Cards: border-radius: 12px, subtle warm box-shadow
  • Selected post: gold left-border
  • Sidebar: deep green bg, gold icon highlights, cream text
  • Today's column: faint gold wash
  • Drag state: card lifts with larger shadow, drop zone glows gold
  • Smooth transitions: 200ms ease on expand/collapse
  • Reel thumbnails: rounded corners, play icon overlay
  • No purple gradients, no Inter font, no cookie-cutter patterns
