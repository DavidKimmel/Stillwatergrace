StillWaterGrace Image Pivot Design

Date: 2026-03-21  |  Approved

Goal: Pivot from video reels to static image posts (scripture singles + carousels) with a cohesive, branded visual identity.

Problem Statement

Reels have not produced the desired quality despite multiple iterations on rendering, captions, and voice. The visual style lacks brand cohesion. Successful faith accounts like @godswillzmessage and @jentezen demonstrate that text-forward image posts with strong typography and consistent visual identity drive high engagement without video complexity.

Visual Brand System

Core Elements

  • Background: SWG green (#2D4A3E) with linen/fabric texture overlay
  • Text color: Cream (#FFF8F0), Georgia serif
  • Accent: Gold (#D4A853) — used for highlighted key phrases (underline-style highlight), verse references, and @stillwatergrace watermark
  • Highlights: Gold semi-transparent underline behind key words/phrases (CSS linear-gradient(180deg, transparent 55%, rgba(212,168,83,0.3) 55%))
  • Format: 1080x1080 (square, Instagram feed standard)

Scripture Post Style

  • Verse reference at top in gold small caps with letter spacing
  • Verse text centered, large Georgia serif, cream color
  • Key phrases highlighted with gold underline
  • @stillwatergrace at bottom in small gold text
  • Green linen-textured background

Carousel Post Style

  • Same SWG palette but with slight variation — lighter green shade or warm parchment on some slides to differentiate from scripture posts in the feed
  • Same Georgia font, gold highlights, @stillwatergrace watermark
  • Visually part of the same brand family but distinguishable at a glance

Reference Accounts

  • @jentezen — dark textured background, large elegant serif, 3.7K likes
  • @godswillzmessage — parchment background, highlighted key phrases, 706 likes
  • @becoming.her2025 — soft minimal, decorative elements
  • @bible_study8551 — clean with pink highlight blocks

Content Types

1. Scripture Single (4 per week)

  • One 1080x1080 image
  • Layout: verse reference (top, gold) + verse text (center, cream, highlighted phrases) + watermark (bottom)
  • Claude generates: verse selection (via api.bible), which words to highlight, Instagram caption with hashtags
  • Posted via Instagram publish_photo endpoint

2. Carousel (3 per week)

  • 3 slides, each 1080x1080
  • Slide 1 (Cover): Hook/title text — e.g., "When You Feel Like Giving Up", "A Prayer for Peace"
  • Slide 2 (Content): Encouragement, prayer, or short story text
  • Slide 3 (CTA): Anchoring Bible verse + "Follow @stillwatergrace for daily scripture"
  • Claude generates: topic, all 3 slides of text, which words to highlight, Instagram caption
  • Posted via Instagram publish_carousel endpoint

Technical Architecture

Image Generation Pipeline

  1. Claude generates content (text, highlights, verse reference)
  2. Jinja2 renders HTML template with content variables
  3. Playwright opens the HTML in headless Chrome at 1080x1080 viewport
  4. page.screenshot() captures PNG
  5. PNG uploads to Cloudflare R2
  6. Content record updated with R2 URL

HTML Templates

TemplatePurpose

templates/images/carousel_cover.htmlCarousel slide 1 — hook/title
templates/images/carousel_content.htmlCarousel slide 2 — encouragement/prayer/story
templates/images/carousel_cta.htmlCarousel slide 3 — verse + CTA

Rendering Engine

  • Playwright (Python package) renders HTML to PNG via headless Chromium
  • Playwright requires its own managed Chromium — does NOT reuse Remotion's Chrome
  • Dockerfile additions: pip install playwright + RUN playwright install --with-deps chromium
  • Viewport set to 1080x1080 for square Instagram format
  • Browser lifecycle: one persistent browser context per Celery worker process (launched on first render, reused). Cleanup on worker shutdown via worker_shutdown signal.
  • Font: Georgia is not available on Linux. Include fonts-crosextra-caladea (metric-compatible Georgia substitute) in Dockerfile. CSS font stack: 'Caladea', 'Georgia', serif. Custom/handwritten fonts can be added later as TTF files.
  • Texture: A real linen texture image (PNG, ~50KB) stored in templates/images/assets/linen-texture.png. CSS background-image with the green base color underneath. Not SVG feTurbulence — real texture looks better.

Claude Output Schema

Scripture single:

  • verse_text — exact verse text
  • verse_reference — e.g., "Psalm 46:10 NIV"
  • highlight_phrases — list of phrases to highlight with gold
  • caption — Instagram caption with reflection + hashtags

Carousel:

  • cover_text — hook/title for slide 1 (max 10 words)
  • cover_highlights — phrases to highlight on cover slide
  • content_text — encouragement/prayer/story for slide 2 (max 80 words — must fit in 1080x1080 at readable size)
  • content_highlights — phrases to highlight on content slide
  • verse_text — anchoring verse for slide 3
  • verse_reference — verse reference for slide 3
  • verse_highlights — phrases to highlight on verse slide
  • caption — Instagram caption

Highlight matching: Claude returns exact substring matches from the slide text. The renderer does case-sensitive string replacement, wrapping matched phrases in the gold highlight <span>. Highlights are per-slide to avoid cross-slide ambiguity.

Technical Decisions

Image Format

All images use feed_1x1 (1080x1080) — this value already exists in the ImageFormat enum. Only feed_1x1 format is generated per content item. The pipeline does NOT create reel_9x16 or story_9x16 variants.

Image Provider

Use existing pil_fallback value in ImageProvider enum for Playwright-rendered images. Not worth adding a new enum value for this.

Carousel Upload Timing

All 3 carousel slide PNGs are uploaded to R2 and their URLs verified accessible before calling publish_carousel. The pipeline uploads sequentially and checks HTTP 200 on each R2 URL before proceeding to Instagram API.

CTA Slide Text

The "Follow @stillwatergrace for daily scripture" text on slide 3 is a fixed string, not Claude-generated. Only the verse text and verse reference are dynamic.

Future considerations: Custom/handwritten fonts for variety. Reels can be reintroduced later using the existing Remotion setup. The image template system is designed to be extensible — new templates can be added without changing the rendering pipeline.
